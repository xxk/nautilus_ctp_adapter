# 归档样板 / Example Archive

**创建日期**：2026-03-27
**最后更新**：2026-03-27
**状态**：archived
**用途**：展示一个已失效或已被吸收的历史文档，应该如何归档并与当前正式口径隔离。

> 本文档仅用于回溯历史决策，不再作为当前正式入口。

---

## 一、归档原因

本样板用于展示常见的三种归档原因：

1. 内容已被新规范吸收
2. 方案已废弃
3. 路径或入口已迁移

---

## 二、现行正式入口

归档文档必须明确写出替代入口，例如：

1. 当前正式入口：`docs/architecture/AI开发导航总览.md`
2. 当前正式规范：`docs/doc_harness_kit/README.md`
3. 当前长期路线图：`docs/changes_topic/roadmap/...`

---

## 三、归档文档最低要求

最低必须保留：

1. 为什么归档
2. 何时归档
3. 替代入口是什么
4. 这份文档现在还能用来干什么

最低不能继续做的事：

1. 继续作为当前正式规则引用
2. 与活跃文档平级放置却不标明已归档
3. 让 AI 误以为它仍然有效

---

## 四、推荐归档头

可直接复用下面这段：

```markdown
**状态**：archived

> 本文档仅用于回溯历史背景，不再作为当前正式入口。
> 当前正式入口：<替代路径>
```

---

## 五、复制后必须替换的内容

1. 当前正式入口路径
2. 归档原因
3. 归档日期
4. 是否仍保留部分历史参考价值
